# Skills del proyecto (las que pidió el dueño, 23 nov)

Skills públicas y gratis (licencia MIT, cada carpeta lleva su LICENSE) que Claude carga al trabajar en este repositorio.
Sirven para que los vídeos animados (bots/estudio) y las páginas queden cada vez mejor.

| Skill | Para qué | De dónde (versión) |
|---|---|---|
| `cast`, `paint`, `bunshin` + `_jutsu/` (Genjutsu) | dirección de arte, movimiento y acabado «premium»; dentro trae GSAP, principios de animación, Three.js/R3F, canvas generativo y auditoría de diseño | github.com/AThevon/genjutsu (a22540b) |
| `motion-design` | principios de animación: curvas, tiempos, escalonados, cómo se mueve algo que «se siente bien» | github.com/lottiefiles/motion-design-skill (d77a9fc) |
| `threejs-*` (13) | escenas 3D en el navegador: geometría, luces, materiales, sombras, animación, posproceso | github.com/cloudai-x/threejs-skills (0e18186) |
| `find-skills` | busca skills nuevas en el catálogo abierto (skills.sh) cuando hace falta algo que no sabemos hacer | github.com/vercel-labs/skills (57217cf) |
| `design-dna` | sacar el «ADN» visual de una referencia (colores, letra, espacios, efectos) y aplicarlo con medidas | github.com/zanwei/design-dna (593e39b) |

Copiadas sin pruebas, imágenes ni documentación para que pesen poco. Para actualizarlas, se vuelven a copiar desde su
repositorio con el mismo nombre de carpeta.

Regla de la casa: una skill que encuentre `find-skills` NO se instala a ciegas. Antes se lee entera, se mira su licencia
(que permita copiarla) y que no mande ejecutar nada raro, igual que se hizo con estas.
